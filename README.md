# Movies Management

This repository contains a Java-based **Movies Management** application built as a Maven project.  
The project demonstrates structured programming, object-oriented design, and basic data handling for a movie collection.

---

## What the Application Allows You to Do

The application enables operations such as:

- Adding new movies to the collection  
- Storing attributes (title, genre, release year, rating, etc.)  
- Displaying all stored movies  
- Searching for specific movies  
- Updating existing movie data  
- Deleting movies  
- Interacting with movies as Java objects in an OOP structure  

## Requirements
- Java 17+ 
- Maven installed 
- A Java-capable IDE

## How to Run the Project

1. Open **IntelliJ IDEA** or **VS Code** with Java extensions installed.  
2. Select **File → Open** and choose the `Movies-Management` folder.  
3. The IDE will automatically load the Maven project using the `pom.xml` file.  
4. Locate the class that contains the `public static void main(String[] args)` method.  
5. Click **Run** to start the application.
